愿景

我们相信，下一代 personal agent 的关键不是拥有更多记忆，而是能持续维护一个与用户同步的 mental model。今天用户的上下文分散在各种地方，如聊天、文档、AI 对话、本地笔记和现实沟通中；AI 每次被调用时都只能看到局部 context，所以它无法真正理解用户当前如何看待一个问题。我们要做的是一个持续更新的 personal mental model layer：低摩擦收集分散 context，并重建用户的心智模型，并在用户需要时，根据心智模型把正确的上下文分发给对应 agent 或工作场景

它有四个核心特性：

1. **持续存在**：1）后台同步存在——在用户未交互时，持续根据现实世界信号更新对用户 mental model 和外部世界状态的理解（**AI能自动挖掘和演化自己的上下文么**？），2）环境式可唤醒存在——在用户想交互时，以近乎零摩擦的方式被唤醒，立即接入当前场景，而不是要求用户打开某个工具并重新解释背景。

2. **低摩擦**：在任何设备上都能访问，并且交互非常低摩擦；无缝接入任何agent工具

3. **上下文智能**：理解你的个人上下文

4. **主动智能**：主动根据现实世界变化演进自己维护的上下文，主动推送用户想要的信息，主动执行协助用户的操作

> 我们不是做一个更大的记忆库，而是做一个持续和用户同步的 mental model。它知道你现在怎么看世界，而不是只知道你过去做过什么。

原型Product Definition Belief

**核心问题**

  • 个人 AI 协作仍然要求用户手动重建现场。

用户必须切到某个 AI 软件，复制材料，解释背景，组织 prompt，再把结果搬回原来的阅读、写作、编码或笔记现场。这打断心流，也让 AI 帮助无法自然嵌入当前工作。

  • 个人 context 没有成为随时在场的环境层。

有价值的上下文分散在 MacBook、手机、浏览器、知识库、文件、聊天记录和历史会话里。它们无法被不同 agent 稳定调用、同步、更新和回写，所以用户需要反复人工搬运。

  • 当前 AI 既不能稳定接上 context，也不能低摩擦理解 intent。

在输出场景里，问题不只是 AI 不知道旧材料，而是它不知道用户此刻正在做什么、卡在哪里、需要哪种帮助。用户仍要把“我现在想要什么”包装成 prompt，才能获得帮助。

  • 个人 context 如果缺少 curation，会从资产变成污染源。

当前 LLM wiki / agent artifact 很容易把 AI 的临时分析、用户的真实立场、外部证据、旧判断和新判断混在一起。AI 后续读取时会把自己的分析当成事实，把已经被用户否定的旧判断继续当真，或把前后转向强行合并。结果是 context 越积累越不可信，用户反而需要花时间审稿、反驳和清理。

**用户**：我

**关键场景**

1. 信息输入场景：我有很多东西想看，包括视频、网站、书籍等等。我希望既能够将我看的内容同步给AI，积累到我自己的知识库，又能维持我的心流状态不被打断。目前需要分享链接/下载文件-切到codex/微信openclaw-上传给codex/微信openclaw-输入ingest提示词。

2. 输出场景：写文章、写代码、做笔记的时候，希望1）能够维持心流，尽量少prompt乃至不prompt（无论是语音还是打字），就能获得AI的帮助，2）AI能够访问我的上下文。目前需要切换到codex/gpt-输入prompt（以及一大堆复制粘贴）-获得回答-贴回来/思考且继续追问。

3. 实时访问场景：我希望能在随时随地都访问我的上下文以及使用AI，并且摩擦尽量小。AI倒是可以到处部署，但是目前上下文都积累在MacBook上，同步有点麻烦（目前的方案是Github）。更进一步地，我希望可以不掏出手机，直接语音+HUD交互。

4. **4. 长期使用与 context 治理场景**

我希望 Context Copilot 能被长期使用，而不是一段时间后因为上下文污染而变得无法提供高质量回答/帮助。AI对上下文的理解应该符合我的理解，并且随着我理解的演变而演变。

**MVP设计**

**OKR**

Objective 1：信息输入时，不打断心流地把外部材料接入个人 context

  • KR1：一键可把当前阅读的内容同步到自己的Context库
  • KR2：可收纳网页、视频、文章等……？
  • KR3：信息收入context库的过程不打断阅读学习的心流

Objective 2：输出现场中，减少 prompt、复制粘贴和切换成本，得到AI帮助

  • KR1：可支持一键语音输入
  • KR2：支持一键完成想要的任务，无需Prompt
  • KR3：支持在任何窗口可Access AI，无需切换

Objective 3：随时访问时，让个人 context 脱离单一设备依赖，可随处访问

  • KR1：手机上可访问带我的上下文的AI
  • KR2：手机上可完成O1、O2
  • KR3：支持语音实时唤醒对话

Objective 4：长期使用上下文follow我的心智模型

  • KR1：自动整理上下文、符合我的理解
  • KR2：现实世界变化演进自己维护的上下文
  • KR3：可推断我没有告诉它的事情

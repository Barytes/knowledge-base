目标：测量学情，想要知道学生哪里会了哪里不会，细粒度。

核心问题：学生知道自己不懂，但是不知道为什么自己不懂，只能靠记忆力，或者错误归因为自己不行。但是实际上只是欠缺了技能包。

**什么是细粒度的学情诊断？**

“认知原因级诊断”。比如：

  • 不是只说“静摩擦力不会”
  • 而是说“学生把最大静摩擦力误当实际静摩擦力”
  • 或“不会在整体法与隔离法之间切换”
  • 或“没有建立共同加速的物理图像”

**粗到细的测评粒度光谱**

| 层级 | 粒度 | 示例 | 评价 |

| --- | ------- | --------------------------------- | --------------- |

| L0 | 总分级 | 数学 62 分 | 最粗，只知道结果 |

| L1 | 模块级 | 有理数较弱，一元一次方程较弱 | 只能指导大方向 |

| L2 | 知识点正确率级 | 数轴 0%，倒数 0%，等式性质 100% | 菁优这个样本主要在这里 |

| L3 | 能力标签级 | 符号意识、运算能力、模型思想得分低 | 截图里的雷达图在这里，但偏抽象 |

| L4 | 题型/子技能级 | 数轴上表示负数会错，合并同类项时系数处理错 | 开始有教学价值 |

| L5 | 错因/误概念级 | 把负号理解成运算符，不理解相反意义的量；把最大静摩擦力当实际摩擦力 | 这才接近陈子深说的细粒度 |

| L6 | 过程证据级 | 根据作答步骤、停顿、改答案、草稿、口述，判断卡在哪一步 | 很细，但采集难 |

| L7 | 干预闭环级 | 给出针对性补救任务，复测后验证错因是否消失 | 真正有壁垒，也最难 |

一、 列夫·维果茨基（Lev Vygotsky）：最近发展区与认知脚手架

列夫·维果茨基是 20 世纪初的苏联心理学家。他的核心理论是，人类的高级认知能力不是独立在真空中产生的，而是在与环境、工具和他人的互动中“内化（Internalization）”而来的。

1. 核心概念：最近发展区 (ZPD) 与脚手架 (Scaffolding)

  • **最近发展区（Zone of Proximal Development）：** 指的是“人类独立解决问题的能力”与“在引导或帮助下解决问题的能力”之间的那段**差距**。
  • **脚手架（Scaffolding）：** 为了帮助人类跨越这段差距，环境需要提供一种“动态支撑”。当人类能力不足时，脚手架提供强力支撑；当人类逐渐掌握能力时，脚手架必须**逐渐隐退（Fading）**，最终让人类独立完成。

2. 对 Agent Harness 的产品启示：护航但不替代

在当前的 Agent 赛道中，许多基础设施试图直接消除问题（即直接把楼盖好），这让 Founder 失去了穿越“最近发展区”的机会，导致他们不仅没有获得对市场的 Conviction，反而产生了智力退化。

  • **重塑 AI 的角色：** 在你的系统中，Agent 就是那个脚手架。当 Founder 在访谈数据中迷失时，Agent 将矛盾点高亮并并排展示（提供支撑）；当 Founder 开始在这个冲突中写下深刻的洞察时，Agent 瞬间静默（脚手架隐退）。
  • **最终交付物是人：** 维果茨基理论最动人的一点是，互动的最终目的不是完成当前的任务，而是**主体的成长**。你的 Agent Harness 最终交付的不是一份“Idea 验证报告”，而是一个“思维被彻底淬炼过、对产品无比笃定的 Founder”。

二、 示能（Affordance）：无摩擦的主体行动引导

Affordance 最早由生态心理学家詹姆斯·吉布森（James J. Gibson）提出，后来由苹果前副总裁唐·诺曼（Don Norman）在其名著《设计心理学》中引入人机交互（HCI）领域。

1. 核心概念：环境的行动暗示

Affordance 的中文常被翻译为“示能”或“可供性”。它指的是**物体本身的属性与使用者的能力之间的一种关系，这种关系决定了物体可以如何被使用，且无需额外解释。**

  • **物理学的例子：** 一个扁平的门板“示能”被推，一个圆形的门把手“示能”被拉，一把椅子“示能”被坐。
  • **你提到的完美比喻：** “马桶和纸巾”就是一种极强的 Affordance。你不需要一个智能体用语音播报“请在此排泄”，马桶的存在本身就提供了一种毫无摩擦的行动环境。

2. 对 Agent Harness 的产品启示：设计“认知示能”

将你在多智能体底层架构上的思考与人类交互结合，你要做的不是设计 Agent 如何执行任务，而是设计 **Cognitive Affordance（认知示能）**。

  • **用空间布局代替指令：** 如果 Founder 需要判断一个 Idea 的市场缺口，不要弹出一个对话框问“你要分析竞品吗？”。相反，Agent 应该在前端画布上渲染出一个带有大块留白的“竞品对比图谱”，并将已知的竞品碎片散落在边缘。这个半成品的空间布局本身就具有极强的“填空示能”，会自然而然地诱发 Founder 亲自去拖拽、对比和思考。
  • **抹平前置摩擦：** 真正阻止人类进行主体动作（如深度思考、复盘）的，往往是那些繁琐的前置准备动作（找录音、翻笔记、开新文档）。Agent 的职责是把这些前置动作在后台用极高的效率全部拉齐，让人类一睁眼，就处于一个“唯有思考可以进行”的高势能环境中。

理论的融合与升华

将维果茨基与 Affordance 结合，你的产品哲学就形成了一个完美的闭环：

1. **维果茨基回答了“为什么”：** 因为人类只有通过亲历挑战（穿越最近发展区）才能获得真实的信念与能力成长，所以系统必须保护人的主体动作，只做脚手架。

2. **Affordance 回答了“怎么做”：** 通过精心布置上下文、数据和前端视觉，提供强烈的认知暗示（递纸），让人类不需要任何启动成本，就能丝滑地进入主体动作。

这两套理论不仅能极大地武装你的产品设计，在未来你向顶尖的 Agent 基础设施团队展示你的 GTM 项目时，这种将底层工程实力与顶层认知科学结合的视野，将是你最差异化的竞争力。

如果要将这种“认知示能”落地到你的第一版产品（比如只做“假设压力测试”模块），你打算设计怎样的前端交互画布，才能让人类不由自主地想要动手去修改自己的商业假设？

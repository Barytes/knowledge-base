做点真东西：现实反馈、作品与作者责任

“做点真东西”不是要求先做宏大项目，而是要求判断离开自我认证，进入一个可能使用、拒绝、反驳或改变它的现实回路。MAKE WHAT LASTS 再把时间加入检验：行动最终留下了什么，是否仍在服务别人，以及作者是否愿意继续为它负责。

来源与证据状态

本页以 Yuzheng Sun / 立正于 2026-08-29 整理并以 CC BY 4.0 发布的 核心主张：做点真东西 为当前主来源，并参考 2026-08-04 的 《我对 Build in Public 的反思》 与 Public Axioms V1。本文是本知识库的主题综合与改写，不是逐字转载，也不替作者本人回答。

四句话描述的是四个尺度

| 表达 | 它解决的问题 | 最低证据 |

| --- | --- | --- |

| 学点真本事 | 在头衔、分数和组织记分牌之外，什么判断与手艺仍然成立 | 能在具体问题中反复产生可观察结果 |

| 做点真东西 | 如何迈出第一步，让现实而非作者自己回答 | 有一个不完全受自己控制、可能拒绝它的反馈回路 |

| MAKE WHAT LASTS | 第一次发布之后，行动留下了什么 | 有人继续使用、信任、引用、观看、改造，或能力与判断被保留下来 |

| 做出你的代表作 | 一生中哪些理解与手艺值得长期负责 | 作品逐渐清楚承载作者的判断、标准、手艺与责任 |

它们不是四个等级，也不是要求每次行动都长成永久资产。“做点真东西”降低的是开始的规模，不是现实标准；一个只使用十分钟、却帮助做出更准确判断的一次性工具，也可能完成了它的任务。

“真”的最低门槛是现实有权说不

一件事是否“真”，不能由投入感、代码量、完整文档、公开掌声或作者身份单独证明。它至少要具体到让外部条件作答：

  • 产品能被使用，也能被放弃；
  • 判断能形成预测，也能被证据推翻；
  • 方法能改变结果，也可能显示无效；
  • 作品能被继续选择，也可能在新鲜感过去后无人回来；
  • 制度能继续赢得信任，也可能因后果失去信任。

现实并不公平，采用也可能来自分发、锁定、权力或潮流，因此“被选择”不是价值的完美测量。它的作用更窄：阻止作者只靠自己宣布成功。

一件作品怎样逐渐有分量

1. 行动与理解互相生成

理解不必在开始前全部完成。好奇、限制、任务或一个不成熟的尝试都可以启动行动；行动制造证据，复盘再把“做了什么”还原为“原先相信什么、实际发生什么、下一步要更新什么”。

2. World model 必须能被反驳

世界模型不是信息收藏，而是对因果、激励、限制与可能后果的明确解释。把它写成能被证据挑战的预测，并主动寻找会改变判断的材料，才能防止重要观点藏进事后叙事。

这与本库 主动摧毁最爱的想法 的认知纪律相通：真正的 conviction 不是拒绝更新，而是一个判断足以支持行动和承担成本，同时仍允许更好证据改变它。

3. 手艺让判断进入身体

许多质量差异无法完全压缩成规则。手艺来自真实问题、反复实践、比较好作品、师承与对后果的注意。AI 可以降低制作和迭代成本，却不会自动给出什么值得做、什么算好、哪些风险要承担。

这也解释了 科学与技艺双层认知模型 与 Taste：感受良质的能力 的分工：显性模型帮助解释和反驳，身体化经验帮助在具体材料里看见差异，两者最后都要对结果负责。

4. 负责任的 authorship 不等于署名

Authorship 包括参与定义：什么应该存在、服务谁、什么标准重要、哪些妥协可以接受、什么证据会迫使它改变，以及谁继续承担后果。个人可以拥有 authorship，目标和标准一致的团队也可以拥有；只有名字出现在页面上，不代表已经承担创作责任。

5. 时间揭示，不替代判断

时间会逐渐暴露：新鲜感过去后是否仍有人使用，维护兴奋过去后作者是否仍愿意负责，外部条件改变后作品是否仍有意义。但重要作品可能多年无人理解，短期成功也可能来自分发优势，所以 lasts 是追问，不是成功公式。

一个 build 有三本账

Build in Public 同时可能产生三类真实但不同的结果：

| 账本 | 记录什么 | 常见误认 |

| --- | --- | --- |

| 作品账 | 是否有用、可靠，是否解决原问题 | demo 跑通就等于可依赖产品 |

| 故事账 | 注意力、声誉、关系、机会与 builder 身份 | Star、点赞或掌声证明长期价值 |

| 商业账 | 采用、复用、留存、付费与增长 | 一次发布等于可持续需求 |

三本账可以互相增强，也可以脱钩。学习实验、原型、Portfolio、内容与产品都是正当任务，但它们需要不同证据。类别偷换才是问题：把内容传播写成产品采用，把学习完成写成生产能力，把一次 launch 写成长期价值。

公开更像传感器，而不是方向盘。它可以让反馈与机会更早到来；如果平台节奏开始决定选题，作品就可能退成故事的原材料。

“做小，但要真”的最小闭环

这不是固定流程，而是一种检查顺序：

1. 写清当前想改变的具体对象，以及暂时相信的机制。

2. 做出一个足以让别人或现实条件作答的最小版本。

3. 提前写下什么反馈会支持、削弱或推翻当前判断。

4. 让真实使用者、数据、材料、同行或运行环境接触它。

5. 区分投入、产出与实际变化，不用完成动作代替结果。

6. 根据证据继续、修改、停止，或明确它只完成了学习任务。

关键不是每一步都公开，而是至少有一次反馈不由作者完全控制，并有能力迫使作者更新。

边界

  • 不是要求每项工作都永存、规模化或成为资产；照护、修复、服务、探索和必要执行可以只回应一个时刻。
  • 不是反 AI、反速度、反就业、反大组织或反分工。组织也能做出真东西，团队 authorship 也可以成立。
  • 不是把知名度、收入或市场采用当作人的价值，也不把无人理解自动美化成高尚。
  • 不是“只要坚持就会成功”。资源、制度、权力、合作者、分发、运气与时代都会改变结果。
  • 不是另一套内部记分牌。若“做真东西”只变成展示身份的新口号，它已经失去现实检验的作用。

Agent 复利工作模式

摘要

这份材料从一道复利数学题出发（1.03^200 = 1.02^200 × 7），说明 AI 工作中的复利效应来源。核心洞察是：

> Agent 的价值不是第一次做得多好，是每一次都在变好。

真正的变革不是在工作流程中「问一下 AI」，而是围绕 Agent 的能力重新设计工作方式，让时间、规则、产出变成可积累的资产。

一、复利原理：2% 与 3% 的差距

Facebook 早期高管 Mike Vernal 被问及 Facebook 成功的最重要原因时，答案是：核心增长团队把每周活跃用户的增长率从 2% 拉到了 3%。

3% 的周增长率，累积 4 年（约 200 周），跟 2% 的周增长率，相差 7 倍。

这就是复利：

1.03 ^ 200 = 1.02 ^ 200 × 7

这个原理同样适用于用 AI 工作：为什么有的人用 AI 做第四次和第一次一样累，而有的人做第四次只需要一个 prompt。

二、电机不是更好的蒸汽机

Eric Schmidt 讲过一个故事：

电机刚被发明时，工厂主的做法很直觉：把中央蒸汽机拆掉，换一台电机，其他一切不变。效率提高了大约 30%。

过了几十年，有人意识到电机可以做得很小。不需要把所有机器用皮带连到一个中央动力源上——每台机器可以有自己的电机。工厂可以围绕生产流程本身来设计，而不是围绕动力源的位置来设计。

流水线诞生了。效率提高了几十倍。

**30% 和几十倍之间的差距不在技术，在于你有没有重新设计工作方式。**

今天的 AI 是一模一样的局面：

| 做法 | 描述 | 效果 |

|------|------|------|

| 蒸汽机思维 | 工作方式不变，只是在某个环节「问一下 AI」 | 30% 提升 |

| 电机思维 | 围绕 AI 的能力重新设计工作方式 | 几十倍提升 |

大多数人在做的事情是：写周报的时候让 ChatGPT 润色一下，做 PPT 的时候让 Gamma 生成一版，写代码的时候让 Copilot 补全。这就是把电机放到蒸汽机的位置——当然有用，但你只拿到了那个 30%。

三、问题根因：工具会了，工作习惯没变

常见的困惑：

  • 「跟着教程能做出来，但自己想不出用在哪」
  • 「用 AI 做的和自己做的差不多，没感觉快很多」
  • 「AI 能帮我写代码，但我的日常工作好像用不上」

这些困惑指向同一个根因——**问题不在会不会用工具，在工作习惯有没有变。**

学了一个新工具，但工作方式没变。还是用老办法做事，只是某个环节换成了 AI。这就是那个 30%。

四、案例一：给腾讯游戏做企业培训

交付内容

  • 24 页主方案 Deck（现场演示 + 会后流转给采购链上的决策者）
  • 3 份独立方向详述 PDF（每份 5-6 页，完整论证不同的培训方向）
  • 1 份提案文档（三个可选项目方向）
  • 多轮需求调研、1v1 访谈、问卷分析

重要 vs 不重要但必要

| 不重要但必要（交给 AI） | 真正重要（人来做） |

|------------------------|-------------------|

| 格式对齐 | 调研——理解业务的真实痛点 |

| 排版 | 归因——5 个人给你 5 种答案，找到统一根因 |

| 文档标准化 | 设计——选方向、定边界、控节奏 |

| PDF 生成 | 沟通——现场 30 分钟的信任建立 |

**用 AI 工作的第一层：不是替代你，是让你把时间花在对的地方。**

第一次用 AI，差不多

第一次用 AI 做，不管用什么工具，结果差不太多：

  • 用 ChatGPT：告诉 AI 你要什么 → 它生成一版 → 你手动调整 → 交付
  • 用 Cursor：告诉 AI 你要什么 → 它读取项目文件 → 生成一版 → 交付

**如果你只做一次，那 ChatGPT、Claude、Gamma、Cursor 的体验差异其实不大。**

复利在第二次开始显现

当你要做第二个类似的项目，差距就出来了：

| 工具类型 | 第二次及以后 |

|----------|-------------|

| ChatGPT/Claude | 每次从零开始，上下文、产出、调好的规则全部留在聊天窗口里 |

| Agent（Cursor/Claude Code）| 做过的内容都变成了文件，调好的规则写进了规则文件，AI 自己读 |

**区别的本质：** ChatGPT 和 Claude 的对话窗口天然缺少积累性。Agent 操作的是本地文件，第一次做的时候建立的资产——文件、规则、上下文——在第二次、第三次自动生效。

五、案例二：做 PPT 这件事本身

同一份 Deck，四次变身

四个版本，面向完全不同的受众，内容相差很大。但从 V2 开始，每次只需要一个 prompt。

V3 是最有说服力的例子——从中文私董会的 deck 变成全英文的 Seattle Startup Summit 演讲稿。受众变了（中国创业者 → 美国创业者），语言变了（中文 → 英文），案例侧重变了，语境完全不同。

为什么能这么快？

因为所有内容都在本地文件里。之前的 HTML、CSS、项目总结、演讲逐字稿、风格调整的规则……AI 读完这些文件，就有了完整的上下文。一个 prompt 说清楚新的方向——「改成英文，面向美国创业者，强调 X 而不是 Y」——它就能生成针对性极强的新版本。

而且，每次积累的不只是内容本身。做 V1 的时候，和 AI 磨合了排版风格、调试了 Reveal.js 的布局参数、调好了配色方案。这些东西变成了 Skill 文件和 CSS 规则。做 V2、V3、V4 的时候，这些磨合成本全部归零。

如果用 ChatGPT 来做同样的事？

| 问题 | 描述 |

|------|------|

| 拖拉拽 | 要把之前的内容复制粘贴过去，但它们分散在不同的聊天记录里 |

| 大量的上下文工作 | 每次都要重新解释：我之前做了什么、这次要怎么改、风格要求是什么 |

| 一直盯着 | 它生成一段你就要看一段，不能离开，因为它没有你项目的上下文 |

| 没有复利 | 第四次做和第一次做，花的时间差不多 |

**ChatGPT 和 Claude 本身很强大。但它的对话窗口天然缺少积累性。**

六、Agent 的复利公式

Agent 的复利来自三个维度的积累：

1. 本地文件 = 持久记忆

你做过的所有内容都在文件里。AI 下次来，不需要你解释——它自己读。

这和 ChatGPT 的根本区别在于：ChatGPT 的记忆在对话窗口里，关掉就没了（或者藏在很难检索的历史记录深处）。Agent 的记忆在你的文件系统里，永远在，而且结构化。

2. 规则文件 = 质量标准

你调好的规则写进文件，永远生效。不需要每次重新说「字号用 0.6em」「配色用 teal」「callout box 用左边框加背景色」。

这些规则文件本身就是资产——你花时间调试出来的对 AI 的「训练」不会丢失。它们跨项目、跨会话、甚至跨工具生效。

3. 迭代 = 越来越快

每次做完，资产又多了一点。下次更快、更准、更少需要人干预。

这就是一个正向循环：

做 → 积累资产（文件、规则、模板、素材）→ 下次更快 → 做更多 → 积累更多资产

复利公式

本地资产 × 持久上下文 × 反复迭代 = 每一次都比上一次更快、更好

**重要认知：这不是「用 AI」，是在「训练 AI」。**

| 心智模型 | ChatGPT | Agent |

|----------|---------|-------|

| 定位 | 「帮我做一件事」 | 「在我的项目里做事」 |

| 结束后 | 做完就结束了 | 每次做完，你的项目就变得更丰富 |

| 目标 | 一次性的任务 | 构建一个越来越好用的工作环境 |

七、一张图总结

                    第一次                    第四次
                    ┌──────┐                 ┌──────┐
  ChatGPT/Claude   │ 3 小时 │  ──────────→   │ 3 小时 │   没有复利
                    └──────┘                 └──────┘

                    ┌──────┐                 ┌──────┐
  Agent (Cursor)   │ 3 小时 │  ──────────→   │ 10 分钟│   复利生效
                    └──────┘                 └──────┘

  差距来源：文件（持久记忆）+ 规则（质量标准）+ 迭代（越来越快）

八、跨工具资产

这些资产是跨工具的。之前的 deck 有的用 Claude Code 做，有的用 Cursor 做。但文件就是文件——.html 是 .html，.css 是 .css，不管是哪个工具生成的。

**不需要纠结到底该用哪个工具。选一个顺手的，然后把精力花在积累资产上。**

九、如何开始

现在可以做的一件事

打开 Cursor，把你最近做过的一个重复性工作变成一个项目。

  • 不是一次对话，是一个有文件结构的项目
  • 把上下文放进去
  • 把规则写下来
  • 把素材存好

下次再做类似的事，你就有了起点。第一次可能省不了多少时间。但第二次、第三次……复利会开始生效。

下一步

把工作流程拆解成可以被 AI 持续优化的模块：

  • 怎么写 Skill 文件
  • 怎么让 Agent 不只是帮你做一件事，而是帮你做一类事
  • 怎么让工作越做越好

核心结论

围绕 Agent 改变工作习惯，让你的时间、规则、产出变成可积累的资产。这就是从 30% 到 10 倍的真正路径。

> Agent 的价值不是第一次做得多好，是每一次都在变好。

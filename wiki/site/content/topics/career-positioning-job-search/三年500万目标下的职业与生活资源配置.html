三年 500 万目标下的职业与生活资源配置

> **状态更新（2026-07-30）：** 用户已被朋友的深圳创业公司裁员，原有每月 2 万元现金流结束。本文“当前处境”与“未来 90 天”中围绕该工作的判断是 2026-07-17 的历史快照，不应继续作为当前现金流前提。最新执行判断见 当前项目收束（2026-07-30）。

当前处境

用户已取得中山大学软件工程硕士学位，目前以每月 2 万元在朋友的深圳创业公司兼职开发并探索 AI Agent 产品。工作可远程，但节奏紧、方向反复。与此同时仍有两篇导师要求收尾的论文，家庭强烈要求读博或进入广州央国企，伴侣在澳门读研并居住珠海，用户还承担家务与照顾小猫。

这不是单纯的职业选择，而是多个主体同时索取时间：朋友、导师、父亲、伴侣和家庭。当前首先稀缺的不是机会，而是完整、可自主配置的注意力。

对 500 万目标的现实判断

先区分 500 万指累计税前收入、可支配现金，还是净资产。三者难度完全不同。

按当前每月 2 万元计算，三年税前收入约 72 万元。即使换到明显更高薪的工作，单靠工资在三年内形成 500 万净资产也不现实。三年 500 万只能来自所有权和非线性上行，例如创业股权、产品利润、销售佣金或高杠杆服务；但这些路径只能提高可能性，不能承诺结果。

因此，500 万适合作为方向约束：不能把全部时间卖给低杠杆任务。它不适合作为三年内必须兑现的生活 KPI，否则容易诱发赌博式创业和对正常积累的否定。

当前主线判断

现阶段不宜立刻读博。已有职业观察表明，读博与用户当前的 Agent Systems 兴趣、身心承受和市场窗口存在明显错配。尚未写完的两篇论文也说明，科研债务已经在持续占用注意力，继续读博会把这种关系延长四到五年。

央国企可以保留为风险对冲，但不应在父亲情绪压力下直接成为主线。是否选择它，应取决于岗位内容、成长资产和生活适配，而不是只看广州、编制或家庭满意。

朋友公司的工作当前有双重价值：提供现金流，也可能提供真实 Agent 产品、用户和商业训练。但“朋友关系 + 月薪”不等于值得长期押注。它必须在 90 天内证明自己能沉淀至少一种可带走资产：真实用户案例、可公开或可讲述的 Agent 系统成果、商业验证能力、可靠 reference，或有明确条款的股权上行。若只有高强度执行和反复改方向，它只是消耗性的过渡工作。

未来 90 天

1. 先固定生活基地

未来三个月选择珠海或深圳作为公开、稳定的主要居住地，不再依靠“替导师科研”的借口维持伴侣关系。地点的标准是能否保护连续工作时间、关系稳定和通勤成本，而不是同时满足所有人。广州家庭事务应改成约定时段，不让家务随机侵入全天。

2. 重谈朋友公司的合作契约

把每月 2 万元对应的工时、职责、优先级、需求变更机制和交付边界写清楚。若公司希望用户承担联合探索和接近合伙人的风险，就应讨论股权、利润分成或明确的里程碑奖励；若只支付工资，就按雇佣关系限制投入，不无限承接创始人的方向波动。

同时要求每四周产生一个外部可验证结果，例如一个真实用户在用、一个付费试验、一个可度量的业务改善，或一个完整的 Agent 系统案例。没有外部结果的忙碌不计入职业成功。

3. 给论文设置封顶预算

论文收尾应被定义为有限债务，不再作为开放式科研。先与导师确认两篇论文各自的最低完成标准、作者责任和最终截止日；每周只给固定时段。大修优先完成，未投稿稿件若长期没有明确投稿窗口或导师持续扩大要求，应重新谈判范围、延期或退出，而不是无限面向导师偏好修改。

4. 同步验证 Agent 就业市场

不要等创业工作结束后再求职。未来 90 天至少完成一轮真实市场验证：形成统一的 Agent Systems Engineer 证据包，定向接触目标团队，参加真实面试或合作沟通。要验证的不是“AI Agent 有没有前途”，而是当前能力能否换来哪些岗位、薪资、合作与能力缺口。

5. 设置 90 天去留触发器

90 天后继续朋友公司的条件是：工作边界改善，并且出现用户、收入、案例、股权上行或强 reference 中的至少两项。否则把它降级为更轻的兼职或退出，转向更成熟的 Agent 团队或稳定工作。

关于父亲的边界

父亲以暴怒或“要死要活”迫使用户服从，已经不是正常职业建议。风险信息可以听，决定权不能交出去。沟通重点应从“说服他 AI Agent 一定成功”改为展示现金流底线、90 天复盘、失败触发器和稳定路径备选。

若父亲出现具体、自伤时间地点明确、正在实施或无法保证安全的表达，应立刻联系当地急救、警方和能到场的亲属，不要独自承担评估和看护责任。除此之外，不在其暴怒时辩论职业方向，只重复边界并结束对话。

结论

当前最优策略不是在读博、央国企、创业和伴侣之间寻找一个同时取悦所有人的答案，而是先结束多头无限责任。

主线可以暂定为：用当前 2 万元现金流换取 90 天窗口，收紧创业合作和论文债务，同时用真实求职与用户反馈验证 Agent Systems Engineer 路线。90 天后按外部结果决定加注、转职或降级。

三年内 500 万不能被规划成确定结果。真正可执行的目标是：一年内形成稳定现金流、市场认可的 Agent 系统能力和一项自己拥有的上行资产。只有这三者同时存在，500 万才从愿望变成小概率但可追求的结果。

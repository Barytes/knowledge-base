# 框架层

这个目录保存高复用、低噪音的判断框架与 query 入口页。

它和 `bridges/` 的区别是：

- `frameworks/` 回答“这类问题该先站在哪个框架上看”
- `bridges/` 回答“把知识和你的判断结合后，具体会得出什么结论”

适合放进这里的页面通常满足至少一条：

- 能作为多次 query 的默认起点
- 能路由到一组常一起调用的 `knowledge/`、`bridges/` 页面
- 能压缩成小而硬的判断框架，而不是一篇完整分析

维护原则：

- 宁少勿多
- 优先合并旧页，不轻易新增新页
- 以链接和路由为主，不重复展开底层内容
- 定期清理已经退化成 bridge 或重复索引的页面

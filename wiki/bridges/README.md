# 桥接层

这个目录保存把外部知识与你的判断框架结合起来的具体分析页面。

例如：

- 带有你视角的主题文章
- 面向具体项目的应用分析
- 同时混合事实判断与你优先级的建议

如果一页里同时出现“材料显示”和“考虑到你一贯的优先级”，而且最终产物是一个具体结论或 memo，它大概率就应该放在这里。

如果一页的主要作用是：

- 为多次 query 提供默认起点
- 路由到常一起读的页面
- 压缩成小而硬的判断框架

那它更适合放进 `../frameworks/`，而不是继续堆进 `bridges/`。

完成态的混合长文放在 [essays/README.md](essays/README.md)。

# 桥接长文

这个目录用于保存已经成形、或接近成形的桥接长文，用来把你的思考方式应用到某个外部主题上。

这些页面通常同时以下列两层为上游：

- `wiki/knowledge/`
- `wiki/self/`

反过来，这些桥接长文也可以被再次阅读，用作 `wiki/self/` 的二级证据源，尤其适合提取：

- 问题 framing 习惯
- 比较与抽象方式
- 写作风格层面的 observations

但它们不是原始证据，因此默认只适合先支持 `observation`，而不适合单篇直接升成高置信度 `pattern` 或 `axiom`。

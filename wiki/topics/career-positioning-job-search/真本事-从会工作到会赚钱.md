# 真本事：从会工作到会赚钱

《真本事》讨论的是：离开学校和组织的内部记分牌以后，怎样获得、打造和放大个人价值，并逐步获得赚钱与自由的能力。本页按来源版本保留作者原本的强表述；2026-08-29 开放 V1 中新增的适用边界单独列出，不用本库的温和措辞替换原书命题。

## 总体问题：组织内完成工作，不自动等于市场持续选择

学校分数、职级、绩效、薪资和汇报都是局部系统里的信号。它们可能真实重要，却不能自动证明一个人能否：

- 看见真实需求和约束；
- 把能力组织成可被评估的结果；
- 让结果接触使用、反馈和拒绝；
- 在平台、岗位或工具改变后继续迁移这套能力；
- 使用杠杆放大价值，同时承担相应风险与后果。

这与 [做点真东西：现实反馈、作品与作者责任](../learning-judgment-mental-models/做点真东西-现实反馈作品与作者责任.md) 的桥可以概括为：**学点真本事，做点真东西。** 前者关心能力是否真实，后者关心能力最终在世界里改变了什么。

## 框架一：三种思维升级

### 客体思维 → 主体思维

**原书表述**把主体思维建立在一句很强的话上：“你是自己人生唯一的、最终的承担者。”在“嫡系文化”的例子里，原书明确提出“嫡系是结果，不是原因”，并认为信任、适配和持续创造价值会使一个人逐渐成为管理者的嫡系。

**2026 开放 V1**没有删除这条思路，但把它改写为一种观察角度：在承认现实约束后，继续问“我有什么选择”“我能影响什么”“需要记录、协商、求助还是退出”。V1 同时明确，信任和既往贡献有时会影响资源，偏好、权力结构和不透明规则也可能独立起作用；不要把“嫡系是结果”用作所有组织的单一解释。

### 固定型思维 → 成长型思维

**原书表述**强调智力、天赋和能力可以通过实践成长，固定型思维会让人因害怕失败而错过高难度项目。**2026 开放 V1**把它整理成一个检查问题：能力能否通过练习、反馈或换环境提高，同时评估时间、成本、机会窗口与任务适配；并明确成长型思维不是成功的必要或充分条件。

### 打分思维 → 多维思维

**原书表述**批评用分数、薪资、职级和排名衡量一个人的单一打分坐标，主张接纳世界的多样和复杂。**2026 开放 V1**进一步把它写成操作问题：先问一个指标遗漏了什么，再为当前决策选择少数真正重要的维度。

## 框架二：手艺思维

“手艺”强调一种偏实践的学习方式：结果能在具体情境中观察和改进；研究越深，越能看见新的质量维度；很多差异不能只靠读书学会。

**原书表述**是：“在现实世界，我认为行动、思考与求知的比例至少是 `6 : 3 : 1`”，并主张用行动引领思考、用思考引领求知。**2026 开放 V1**保留这个数字，但把它标为“提醒不要只输入不实践的启发式”，并指出探索期、危险任务、基础不足或反馈昂贵时比例可以不同。

**原书表述**给出两条捷径：向在相关领域拿到具体结果的人学习；向老板学习，因为老板通常有值得学习的能力，而且真心请教会传递认可和尊重。**2026 开放 V1**保留两条路径，同时加上“关系安全、对方确有相关经验”的条件，并说明职位本身不保证判断正确。

## 框架三：财务自由变量

书中把财务自由简化为“被动收入能够覆盖支出”，并用时间、支出、收入与收益率检查长期路径：

```text
Σ(收入 - 支出) × 收益率 > 支出
```

这只是示意关系，不是完整财务模型。现实还要考虑税、通胀、波动、流动性、债务、家庭责任、保险与风险承受能力。

- **时间**：更早开始可能扩大复利效应。
- **支出**：检查地位消费和广告驱动需求，也不能忽略必要生活与照护责任。
- **收入**：投资自己可能提高未来收入，但比例应服从现金流与可验证回报。
- **收益率**：最难稳定提高，要警惕认知错配、FOMO、情绪驱动和“低风险高回报”。

材料中的 `15%/年 vs 5%/年` 等数字是演算设定，不是预期回报。具体投资决策不能只靠本框架。

## 框架四：个人价值公式

**原书表述：**

> **个人价值 = 了解市场 + 打造产品 + 利用杠杆**

原书还明确提出“个人价值由市场需求决定”，并把公式用于求职、晋升、转型、副业与创业等一切“走向市场”的场景。

**2026 开放 V1：**

> **了解市场 × 打造产品 × 利用杠杆**

V1 说明乘号表示三个维度互相制约，不是可计算等式，也不定义人的价值。这里存在真实的版本差异：本页保留原书的加法公式，也保留作者在 2026 V1 中给出的乘法重述。

**本库应用边界：**当查询涉及商业交换、求职和收入时，可以把公式中的“个人价值”理解为个人市场价值；这不是对原书用词的改名，而是避免把市场定价扩张为人的道德、关系或存在价值。

### 了解市场

**原书表述**要求先问市场需要什么、人们愿意为哪类结果付费，并强调市场不按个人的自我叙事定价。努力和技能难度不能单独证明市场价值。

“先学阿拉伯语”的思想实验就是这条命题的原书表达：如果每道题的价格用陌生语言标注，应先学会读懂价格，再选择值得做的题。

### 打造产品

把经历、技能或方案组织成能被真实对象评估的东西，并区分三层：

| 层 | 观察什么 |
| --- | --- |
| 投入 | 花了多少时间和精力 |
| 产出 | 做出了什么报告、代码、方案或服务 |
| 成果 | 下游决策、收入、成本、风险、用户或公共结果发生了什么变化 |

成果可能滞后、多人共同创造或难以量化。维护、安全、研究和照护也不能只用短期商业结果定价。三层用于补足信息，不是给所有劳动排固定等级。

一个可评估产品通常经过：接触真实需求 → 做出最小可评估版本 → 投放测试 → 根据反馈迭代。简历、公开作品、副业和创业都可以使用这个循环，但不要求每个人都公开或创业。

### 利用杠杆

杠杆把投入差异放大到结果。公司品牌、代码、内容、关系、分发、资本、行业趋势与 AI 都可能成为杠杆；同一杠杆也会放大错误、风险与权力不对称。

**原书表述**认为职场杠杆的风险与收益常常不完全对称：很多情况下，做成后的上升空间很大，做砸后的后果往往有限；有时项目失败积累的试错经验甚至可能帮助晋升。原书也在同一段明确给出前提：不能触碰底线，不能在高合规、高责任场景中乱上杠杆，这类风险并不小。

**2026 开放 V1**把高杠杆情境概括为“用心程度对结果影响巨大的场景”，并明确 `10 倍`不是通用预期。实际应用仍要问目标与谁一致、谁承担下行、谁获得上行。

## 框架五：道、天、地、将、法

这套职业选择透镜借用《孙子兵法》的五层结构：

| 层 | 检查什么 |
| --- | --- |
| 道 | 如何理解问题与判断机会 |
| 天 | 行业、周期与时代变化 |
| 地 | 公司平台、业务位置与资源 |
| 将 | 领导和关键同事的标准、支持与风险 |
| 法 | 方法、技能与执行是否解决当前瓶颈 |

**原书表述**明确使用“选择大于努力”：如果“道、天、地、将”层面选错方向，“法”再精妙也可能事倍功半；行业、公司、领导与团队不对，个人再勤奋也往往难得到等量回报。

**2026 开放 V1**保留五层结构，同时写明“选择与努力不是固定大小关系；不同阶段、约束和备选项会改变哪一层最重要”。本页并置这两个版本，不把后者写成对前者的裁决。

判断公司或岗位时，可以检查行业与业务阶段、现金流和风险，公司是否增加可迁移能力与未来选择权，岗位是否有清晰成功标准、支持条件与评估方式。同一公司里的业务、直属领导和项目可能构成三个不同的职业世界。

## 框架六：少数高价值工作

**原书表述**要求抓住工作中 `10%` 的核心价值，并用价值可能相差几十倍来强调优先级。**2026 开放 V1**把 `10%` 与“几十倍”标为强调价值差异的启发式，而非固定分布。应用时可以追问：

1. 把这件事做好，会带来什么级别的成果？
2. 如果不做，最坏会发生什么？
3. 产出能否继续追到一个真实变化，还是只停在内部记分牌？
4. 减少它会把成本或风险转嫁给谁？

减少低价值工作要考虑职责、团队公平、关系与风险。重复、维护、协调和支持不是天然低价值；参见 [fake work：从内部记分牌到真实结果](fake-work-从内部记分牌到真实结果.md)。

## 框架七：手艺、坚持与长期选择权

**原书表述**给出“成功 ≈ 手艺 + 坚持”的简约公式，并认为手艺质量足够高时，机会往往会主动出现；坚持一年和十年，会遇到与不同功力匹配的机会。

**2026 开放 V1**保留这条公式，同时说明它没有写入资源、健康、时机、关系、结构和运气等全部变量；把“机会主动出现”改写为高质量且可见的手艺“可能增加机会出现的概率”。

**原书前言**明确提出“本职工作和副业的结合，才是破局之路”，并把它称为作者亲身实践后认为最合理、最高效的路径：用本职工作提供起点和成长平台，让副业直面商业规则并逐步发展为个人事业。

**2026 开放 V1**没有把这句话原样写入框架，而是用“保留丛林能力”表达平台外验证，并明确这不要求每个人做副业或公开竞争。两种表述均保留；具体查询应先说明引用的是原书主张还是 2026 V1。

## 从框架进入一次具体职业判断

1. **先写事实与约束**：行业、岗位、现金流、权力关系、健康、家庭、法律与退出成本。
2. **定义当前交换对象**：目标市场或组织究竟在为什么结果付费。
3. **做一个可评估对象**：作品、工作样本、案例、简历叙事或真实任务，而不是只增加输入。
4. **接触反馈**：让用户、招聘者、同行、客户或运行结果有能力拒绝当前判断。
5. **检查杠杆与归属**：价值会沉淀在哪里，谁承担下行、谁拥有成果和选择权。
6. **根据证据更新**：继续、收缩、换位置或停止；不要用坚持本身证明方向正确。

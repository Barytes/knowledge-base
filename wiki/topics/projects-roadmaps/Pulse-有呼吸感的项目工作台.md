# Pulse：有呼吸感的项目工作台

> 一个新产品设想，从 clawhouse 的反思中生长出来。

## 产品定位

**Pulse 是一个移动端优先的项目工作台——项目作为主语，agent 退到幕后。**

核心意象：项目不是静态数据堆，而是**有呼吸感的东西**。你打开它，能看到它在"活着"——在呼吸、在思考、在等待、在焦躁。

---

## 核心概念

### 项目有呼吸感

不是静态 dashboard，而是项目状态有某种**动态气息**：

| 状态 | 视觉表达 |
|------|----------|
| agent 工作中 | 轻微"心跳"动画——不是进度条，而是抽象的存在感 |
| idle | "睡着"——视觉上有静止感、宁静 |
| 出现问题 | "焦躁"——颜色或节奏变化，吸引注意 |
| 等待用户输入 | "呼吸等待"——温和的脉动 |

**酷的点**：项目不再是一堆数据，而是有"生命感"的东西。你看到它就知道它在干嘛，不需要读文字。

### 对话是树，不是线

大多数产品的对话是"一长串消息"。但 Pi 的 JSONL 本身就是树状结构——有分支、有节点。

**Pulse 把对话渲染成一棵可探索的树**：

- 可以点击任意节点，"从那里分叉继续"
- 可以看到"当时为什么走这条路，而不是另一条"
- 可以合并分支、回溯、重新选择
- 关键决策点有标记——转折点、犹豫点、分支点

**酷的点**：对话变成**可探索的决策空间**，不是线性历史记录。

### 时间胶囊：冻结与解冻

做一个功能：**"冻结此刻"**。

点击一个按钮，把当前的项目状态、对话、agent 知道的东西打包成一个"胶囊"。之后可以随时"解冻"——回到那个时刻继续。

**用途**：
- "上周三做的那版"——冻结一个里程碑
- "还没加那个功能时的状态"——冻结一个干净版本
- "这个方向先不走了"——冻结一个分支，之后可能回来

**酷的点**：不是 git branch（代码状态），而是**协作状态**。胶囊之间可以跳转，像时间旅行。

### 极简主义美学

不走"功能丰富"路线，走**极简美学**：

- 单色或双色配色（比如深色背景 + 一个强调色）
- 无装饰、无图标堆砌、无卡片网格
- 只有必要信息：项目名、状态、下一步
- 有"留白"和"呼吸空间"

**酷的点**：像一台精密仪器，而不是一个吵闹的 app。它不抢注意力，但你打开它就知道该干嘛。

### 移动端原生手势

不做"缩水的桌面版"，而是**移动端原生体验**：

| 手势 | 动作 |
|------|------|
| 左右滑动 | 切换项目，像切卡片 |
| 长按 | 进入"深度模式"——对话历史树 |
| 双击 | 立刻回到最近的活跃对话 |
| 捏合缩放 | 项目概览 → 项目详情 → 对话节点 |

**酷的点**：这些交互桌面版做不到，是移动端独有的"手感"。

## 不做什么

| 不做 | 原因 |
|------|------|
| 团队协作 | Slock/multica 已经做了 |
| 任务系统 | multica 已经做了 |
| 人格化 | OpenClaw 已经做了 |
| 云端同步 | 云端产品天然解决 |
| chat UI | 太常见了，不是这个方向 |
| 桌面版优先 | 移动端才是独特体验所在 |

## 最小但酷的版本

如果做一个 MVP，我会选这四个：

1. **树状对话历史**（利用 Pi JSONL 的天然结构）
2. **项目有呼吸感**（简单的动态状态表达）
3. **极简美学**（禅意风格，不堆砌）
4. **移动端手势**（滑动切换、长按进入）

这四个加起来，是一个没人做过的工作面——**项目作为有生命的东西，对话作为可探索的树，交互作为手感，美学作为留白**。

## 技术依赖

- **Pi agent 的 JSONL 格式** — 天然支持树状对话结构
- **移动端开发** — React Native 或 Flutter
- **状态同步** — GitHub / iCloud / 自建后端（可选）

## 与 clawhouse 的关系

Pulse 从 clawhouse 的反思中生长出来，但定位已经不同：

| | clawhouse | Pulse |
|---|-----------|-------|
| 核心问题 | 多设备同步 | 新工作面抽象 |
| 主语 | agent + session | 项目（有呼吸感） |
| 交互 | 看对话历史 | 探索对话树 |
| 美学 | 未强调 | 极简禅意 |
| 独特价值 | 小众刚需 | 体验创新 |

**clawhouse 消解在 Pulse 里**——不再是"解决痛点"，而是"创造新体验"。

---

## 为什么叫 Pulse

**Pulse = 脉搏、跳动、生命力。**

项目不是死的数据，而是有脉搏的东西。你打开 Pulse，能看到你的项目在呼吸、在等待、在思考。

这个名字也暗示了核心交互：不是"点击查看"，而是"感受状态"。

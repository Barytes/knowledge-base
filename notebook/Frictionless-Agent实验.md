## 现有Agent产品的5 种交互模式：
1. **Chat Surface Agent**  
    代表：ChatGPT Agent、Replit Agent  
    特征：用户从一句自然语言目标开始，agent 自己找路径。
2. **Workspace Agent**  
    代表：Codex、Claude Code、Cursor  
    特征：agent 在一个工作空间里读文件、改文件、跑命令、调用工具。任务可以是写代码，也可以是写文档、整理资料、跑分析、生成报告、维护知识库。
3. **Assignment Agent**  
    代表：Devin、Jules、GitHub Copilot coding agent、Codex cloud tasks  
    特征：用户像派活给同事一样，把 issue / ticket / prompt 丢出去，agent 异步完成。
4. **Reviewable Artifact Agent**  
    代表：Codex、Claude Code、GitHub Copilot、Jules、Devin  
    特征：交互重点不是聊天过程，而是 plan、diff、commit、PR、日志、测试证据。用户主要做验收。
    
5. **Embedded Business Agent**  
    代表：Microsoft Copilot Studio、Salesforce Agentforce、Google enterprise agents  
    特征：agent 嵌在 CRM、Teams、Slack、SharePoint、Jira、企业流程里，普通用户不需要理解 agent，只是在原工作流里触发它。

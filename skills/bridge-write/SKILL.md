# Bridge Write

## Goal

Produce a useful applied analysis without collapsing world evidence and user-specific judgment into one layer.

## Contract

- Consult the relevant `wiki/topics/` and `wiki/self/` material.
- Keep source claims, user preferences, tensions, and agent recommendations distinguishable.
- Do not present personal preference as objective fact or hide disagreement between the layers.
- Save an authorized durable output under the relevant `wiki/topics/<topic>/`; use `essays/` only for finished longform work.
- Update links and append a `query` log entry when a maintained page changes.

Use `schemas/query.md` for evidence and write-back policy. Choose the analysis method and output structure that best fit the task.

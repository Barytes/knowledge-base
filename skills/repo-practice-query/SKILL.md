# Repo Practice Query

## Goal

Answer a narrow repository question without repeatedly exploring the entire codebase.

## Contract

- Start from an existing maintained repo map when one is available; create or request a minimal map only when necessary.
- Revisit the evidence anchors relevant to the question rather than restating the whole map.
- Keep observed behavior, inferred engineering principle, portability judgment, and recommendation distinguishable.
- Explain the failure mode a mechanism addresses before treating it as a reusable practice.
- Do not universalize a project-specific implementation or hide missing evidence.
- Follow `schemas/query.md`; update a maintained repo note only when write-back is authorized and useful.

Choose the investigation method and answer structure that best fit the question.

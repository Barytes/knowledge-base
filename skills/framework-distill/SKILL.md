# Framework Distill

## Goal

Make recurring distinctions and decision lenses reusable without turning `wiki/frameworks/` into a second topic directory.

## Contract

- Distill from maintained `wiki/topics/` evidence; do not import user-specific claims from `wiki/self/`.
- Promote material only when it will help route or structure multiple future questions.
- Prefer improving an existing framework over creating a near-duplicate.
- Keep the framework compact and link to source pages instead of copying them.
- Update `wiki/frameworks/router.md` and other navigation only when routing meaningfully changes.
- For authorized changes, append a concise log entry and run relevant link and site checks.

Useful framework content may include diagnostic questions, reusable distinctions, tensions, and source routes. Their selection and presentation are left to the agent.

Consult `schemas/query.md`, `schemas/lint.md`, and the relevant framework pages as needed.
